The Reluplex case-split tree

NN Verification · Chapter 7 · companion to Albarghouthi (2021) §7.3–§7.4.

The 2-2-1 ReLU toy network from Ch 2 has two ReLUs, so Reluplex's case-split tree has at most $2^2 = 4$ leaves — exactly the four colored regions from Ch 5. On each leaf the network is purely linear and the verification condition reduces to a small LP that Simplex closes in a few pivots. Set a robustness spec and press Solve all leaves to watch Reluplex enumerate.

Case-split tree

Click a leaf to expand its details. Green = closed (LP infeasible — pattern verifies vacuously). Red = open (LP feasible — Reluplex returns a counterexample from this leaf).

Reference: Albarghouthi, Introduction to Neural Network Verification, Ch 7 (arXiv:2109.10317). The tree shape is the limit case where Reluplex case-splits on every ReLU. Real Reluplex (Katz et al., CAV 2017) only splits when local pivots loop more than $\tau$ times — on this toy network it would close most leaves with pivots alone, no splits needed. The widget enumerates all leaves anyway because that is the easiest visualisation of the full state space.

The per-leaf LP feasibility is computed by sampling the polytope $\{$pattern constraints$\}$ $\cap$ $\varepsilon$-ball $\cap$ $\{y > M\}$ on a 81×81 grid. With piecewise-linear objectives the worst-case input is always a polytope vertex, so the grid hits an exact violator (when one exists) up to floating-point.
