Interval propagation through the toy network

NN Verification · Chapter 8 · companion to Albarghouthi (2021) §8.3–§8.6.

The interval abstract domain tracks every quantity in the network as a real-valued interval $[l, u]$. Affine nodes propagate via $\min/\max$ over the corners; ReLU is monotone, so $\mathrm{ReLU}^a([l, u]) = [\mathrm{ReLU}(l), \mathrm{ReLU}(u)]$. Drag the anchor of an $\ell_\infty$ ball to set the network's input interval; the site re-runs interval propagation node-by-node and shows the resulting certified output range against the true output range (sampled). The gap between the two is the price of the interval domain's non-relational simplicity.

The four presets walk you through the chapter's headline observation: intervals are exact on a single ReLU activation region (zero gap), and lose precision sharply once the input range straddles a boundary.

The “true” output range is computed by 81×81 grid sampling — exact up to floating point because the network is piecewise-linear with vertices at the ε-ball corners. The interval-domain pass uses the textbook formulas verbatim.
