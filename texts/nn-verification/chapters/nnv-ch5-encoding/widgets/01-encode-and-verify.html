Encode and Verify

NN Verification · Chapter 5 · companion to Albarghouthi (2021) §5.1–§5.4.

The canonical 2-2-1 ReLU toy network from Ch 2, $y = \mathrm{ReLU}(x_1 + x_2) + \mathrm{ReLU}(x_1 - x_2)$, encoded as an LRA formula. Each affine node becomes an equality; each ReLU becomes a disjunction $(\mathrm{in} > 0 \Rightarrow \mathrm{out} = \mathrm{in}) \wedge (\mathrm{in} \le 0 \Rightarrow \mathrm{out} = 0)$. With two ReLUs the verifier sees up to $2^2 = 4$ activation patterns — drawn below as four colored regions partitioning the input plane. Pose a robustness query, then press Verify and watch the case-split decide whether the spec holds.

Reference: Albarghouthi, Introduction to Neural Network Verification, Ch 5 (arXiv:2109.10317). The case-split “one polytope per ReLU activation pattern” is the literal mental model for Reluplex (Ch 7) and α,β-CROWN — the difference is that those algorithms avoid fully enumerating $2^k$ patterns by branching lazily and pruning with bounds. On the toy net we just enumerate.

Verification uses sample-and-check on a 121×121 grid within each pattern's polytope intersected with the $\varepsilon$-ball. With piecewise-linear post-conditions a counterexample (when one exists) is always at a polytope vertex so the grid is cheap and exact up to floating-point. A real LP solver (Ch 6) replaces the sampling.
