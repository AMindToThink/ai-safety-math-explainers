Construct the DAG

NN Verification · Chapter 2 · companion to Albarghouthi (2021) §2.5–2.6.

Albarghouthi defines a neural network as a directed acyclic graph $G = (V, E)$ in which every non-input node $v$ carries a function $f_v : \mathbb{R}^{n_v} \to \mathbb{R}$ and the network's value at each node is given recursively by $\mathrm{outs}(v) = f_v(\mathrm{outs}(v_1), \ldots, \mathrm{outs}(v_{n_v}))$. Below is the canonical 2-2-1 ReLU network that this companion will reuse in every later chapter, drawn as a DAG with empty weight slots. Why these three targets? sum-relus uses the identity weight matrix and rules out the trap of always reaching for the canonical $(1,1)/(1,-1)$ split. abs-sum is the network this companion reuses in every later chapter — its four activation patterns split $[-2,2]^2$ into four linear pieces, which is what the abstract domains of Part III approximate. ridge illustrates that a piecewise-linear target with a single “kink” only needs one ReLU, even though the architecture has two hidden units (set the unused weights to zero).
